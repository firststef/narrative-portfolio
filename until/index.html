Case study

Streamer UNTIL

A first-person horror game where you livestream from an abandoned bunker and a simulated chat reacts to everything you do. The chat is not decoration. It is the antagonist.

Four-person game jam team. I owned the narrative system end to end: the writing, the tool it is written in, and the simulation underneath it.

The game jam's theme was social media. I wanted to build horror around it, so I made the player a small streamer broadcasting from an abandoned building for views. That gave the game two kinds of fear. One is the monster in the dark. The other is social pressure, which became the second theme of the game: the chat keeps demanding, and you keep performing, because the moment people stop watching you are done.

A live chat on screen at all times is a problem for horror, which usually needs isolation. So the chat is not company, it is the threat. The viewership meter is a lifeline, and if it hits zero the stream ends. You raise it by doing what the chat dares you to do, but the same noise that keeps you alive draws the monster, and the higher your viewership climbs, the harder it hunts you.

Every line the chat says has a price. Writing a bark is not writing flavor, it is deciding how many viewers a moment wins or loses, and how much danger that buys.

01

The bark sheet

The chat runs on 289 authored lines: reactions, goads, dares, and the panicked floods that hit when the monster is near. Each line carries a trigger, a viewership effect, and a tone. The full sheet reads like a production bark document, grouped by phase and trigger.

02

The tool I wrote them in

I did not hand-code every reaction. I built a node-based chat graph editor in Unity, so a teammate who does not program can follow a trigger through its conditions and rewrite what the chat says. Fifteen node types compose the whole behavior: triggers, message pools, timed dares, viewer-count effects, flags and conditions, and floods.

03

How it works

A trigger fires when the player gazes at something, idles, or trips a volume, and publishes onto a shared event bus. The chat manager runs the matching branch of the graph, then asks a viewer simulation which personality would speak this kind of line. Viewers carry five traits, so a jump scare tends to come from the fearful and a dare from the trollish and the brave. The line is parsed for its emoji and mentions, rendered into the feed, and its viewership effect is layered onto a meter that ends the run at zero and, on the way there, decides how hard the monster hunts. Toxic attention, made systemic.
